# Loops: Repeating Code

What if you want to print "Building a house" 100 times? You could write 100 print statements... or you could use a loop.

A **loop** repeats code multiple times.

## The Problem

```python
print("Building house 1")
print("Building house 2")
print("Building house 3")
print("Building house 4")
print("Building house 5")
# ... 95 more lines?
```

This is tedious and error-prone.

## The Solution: `for` Loop

```python
for i in range(5):
    print("Building a house")
```

Output:
```
Building a house
Building a house
Building a house
Building a house
Building a house
```

Five lines of output from two lines of code.

## Breaking Down the `for` Loop

```python
for i in range(5):
    print("Building a house")
```

| Part | Meaning |
|------|---------|
| `for` | Start of the loop |
| `i` | A variable that counts each round |
| `in range(5)` | Repeat 5 times |
| `:` | Required colon |
| `    print(...)` | Indented code that repeats |

## What is `range(5)`?

`range(5)` gives you the numbers: 0, 1, 2, 3, 4

That's 5 numbers, starting from 0.

```python
for i in range(5):
    print(i)
```

Output:
```
0
1
2
3
4
```

**Note:** It starts at 0 and stops *before* 5. This surprises beginners, but you'll get used to it.

## Using the Counter

The variable `i` changes each time through the loop:

```python
for i in range(5):
    print("Building house number", i)
```

Output:
```
Building house number 0
Building house number 1
Building house number 2
Building house number 3
Building house number 4
```

## Starting from 1 Instead of 0

If you want to count from 1 to 5:

```python
for i in range(1, 6):
    print("House", i)
```

Output:
```
House 1
House 2
House 3
House 4
House 5
```

`range(1, 6)` means: start at 1, stop before 6.

## For Your 3D City

Build multiple buildings:

```python
print("=== Building My City ===")

for i in range(1, 6):
    print("Placing building", i, "on the map")

print("City complete!")
```

Output:
```
=== Building My City ===
Placing building 1 on the map
Placing building 2 on the map
Placing building 3 on the map
Placing building 4 on the map
Placing building 5 on the map
City complete!
```

Notice: "City complete!" only prints once - it's outside the loop (not indented).

## Combining Loops with If Statements

You can put `if` statements inside loops:

```python
for i in range(1, 11):
    if i > 5:
        print("Building", i, "- Skyscraper")
    else:
        print("Building", i, "- House")
```

Output:
```
Building 1 - House
Building 2 - House
Building 3 - House
Building 4 - House
Building 5 - House
Building 6 - Skyscraper
Building 7 - Skyscraper
Building 8 - Skyscraper
Building 9 - Skyscraper
Building 10 - Skyscraper
```

## Indentation is Crucial

What's inside the loop vs outside:

```python
for i in range(3):
    print("Inside loop")   # Runs 3 times
print("Outside loop")      # Runs once, after loop ends
```

Output:
```
Inside loop
Inside loop
Inside loop
Outside loop
```

## Hands-On Exercise

Create a file called `city_builder.py`:

```python
print("=== City Builder ===")
print()

num_buildings = int(input("How many buildings? "))

for i in range(1, num_buildings + 1):
    print("Built building", i)

print()
print("City complete with", num_buildings, "buildings!")
```

### Why `num_buildings + 1`?

If the user enters 5, we want buildings 1-5.
- `range(1, 5)` gives 1, 2, 3, 4 (stops before 5)
- `range(1, 6)` gives 1, 2, 3, 4, 5 (stops before 6)

So we use `range(1, num_buildings + 1)`.

### Try It

Run with different inputs:
1. Enter `3` - how many buildings?
2. Enter `10` - how many buildings?

## Key Takeaways

1. **`for i in range(n):` repeats code n times**
2. **`range(5)` gives 0, 1, 2, 3, 4** - starts at 0, stops before 5
3. **`range(1, 6)` gives 1, 2, 3, 4, 5** - starts at 1, stops before 6
4. **Indentation defines what's in the loop** - indented code repeats
5. **The variable `i` counts each round** - use it to track progress
