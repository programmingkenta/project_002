# Elif: Multiple Conditions

With `if` and `else`, you have two paths: true or false. But sometimes you need more options.

## The Problem

Imagine categorizing buildings by height:
- Under 50m → "House"
- 50-100m → "Office building"
- Over 100m → "Skyscraper"

That's three categories. `if`/`else` only gives you two.

## The Solution: `elif`

`elif` means "else if" - another condition to check:

```python
height = 75

if height > 100:
    print("Skyscraper")
elif height > 50:
    print("Office building")
else:
    print("House")
```

Output: `Office building`

## How It Works

Python checks conditions from top to bottom:

1. Is `height > 100`? (Is 75 > 100?) → No, skip
2. Is `height > 50`? (Is 75 > 50?) → Yes! Run this block
3. `else` is skipped because we already found a match

**Once one condition is true, Python stops checking and skips the rest.**

## The Pattern

```python
if condition1:
    do this
elif condition2:
    do this instead
elif condition3:
    or do this
else:
    if nothing matched, do this
```

You can have as many `elif` blocks as you need.

## Order Matters

Watch out! Python stops at the first true condition:

```python
height = 150

# Wrong order
if height > 50:
    print("Office building")  # This runs! (150 > 50 is true)
elif height > 100:
    print("Skyscraper")       # Never reached
```

Output: `Office building` (wrong - 150 should be a skyscraper)

```python
height = 150

# Correct order
if height > 100:
    print("Skyscraper")       # This runs first
elif height > 50:
    print("Office building")
```

Output: `Skyscraper` (correct)

**Rule: Check the most specific condition first.**

Categorize buildings with colors:

## Key Takeaways

1. **`elif` means "else if"** - another condition to check
2. **Python checks top to bottom** - stops at the first true condition
3. **Order matters** - put the most specific conditions first
4. **`else` is optional** - catches anything that didn't match
