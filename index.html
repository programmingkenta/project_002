Technical Challenges Solved

Real-world data engineering problems and their solutions

🔗

XLink Reference Resolution

PLATEAU LOD2 uses xlink:href="#poly-xxx" references instead of inline polygons

→ Pre-built polygon cache for O(1) lookups instead of O(n²) document searches

🌐

Coordinate Transformation

Input data in JGD2011 / Japan Plane Rectangular CS IX (EPSG:6677)

→ Equirectangular projection converting lat/lon to local meters

🛤️

Road Z-Fighting

Roads initially invisible due to z-fighting with ground plane

→ Elevated roads 0.5m with increased contrast and white edge lines

💾

Memory-Efficient Loading

600+ MB PLATEAU data files exceed GitHub limits

→ Parse and extract only relevant geometry, serialize to compact JSON

📄 xlink_resolution.py — The Key Optimization
# Build polygon cache for O(1) lookups (instead of O(n²) searches) def build_polygon_cache(root, ns): cache = {} for poly in root.findall(".//gml:Polygon[@gml:id]", ns): poly_id = poly.get("{http://www.opengis.net/gml}id") cache[poly_id] = poly return cache # 6,299 polygons → instant lookup
