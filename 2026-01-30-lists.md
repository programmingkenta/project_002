# Lists: Storing Multiple Values

So far, each variable holds one value. But what if you want to store 10 building names? 100 building heights? You need a **list**.

## What is a List?

A list is a variable that holds multiple values in order:

```python
buildings = ["House", "Shop", "Tower", "Hospital"]
```

This single variable `buildings` holds 4 items.

## Creating a List

Use square brackets `[ ]` with items separated by commas:

```python
colors = ["red", "blue", "green"]
heights = [50, 100, 200, 75]
mixed = ["Tower", 150, "blue"]  # Can mix types
empty = []  # Empty list
```

## Accessing Items by Position

Each item has a position number called an **index**. It starts at 0:

```python
buildings = ["House", "Shop", "Tower", "Hospital"]
#              0        1        2         3
```

Get an item using square brackets:

```python
buildings = ["House", "Shop", "Tower", "Hospital"]

print(buildings[0])  # House
print(buildings[1])  # Shop
print(buildings[2])  # Tower
print(buildings[3])  # Hospital
```

**Remember:** The first item is index 0, not 1.

## Changing an Item

```python
buildings = ["House", "Shop", "Tower"]

buildings[1] = "Mall"  # Change "Shop" to "Mall"

print(buildings)  # ['House', 'Mall', 'Tower']
```

## Adding Items

Use `.append()` to add an item to the end:

```python
buildings = ["House", "Shop"]

buildings.append("Tower")
buildings.append("Hospital")

print(buildings)  # ['House', 'Shop', 'Tower', 'Hospital']
```

## How Many Items?

Use `len()` to count items:

```python
buildings = ["House", "Shop", "Tower"]

print(len(buildings))  # 3
```

## Looping Through a List

This is where lists get powerful. You can process every item:

```python
buildings = ["House", "Shop", "Tower", "Hospital"]

for building in buildings:
    print("Building:", building)
```

Output:
```
Building: House
Building: Shop
Building: Tower
Building: Hospital
```

The variable `building` takes each value in turn: first "House", then "Shop", then "Tower", then "Hospital".

## For Your 3D City

Store your city's buildings in a list:

```python
city = []

city.append("Town Hall")
city.append("Hospital")
city.append("School")
city.append("Mall")

print("My city has", len(city), "buildings:")

for building in city:
    print("-", building)
```

Output:
```
My city has 4 buildings:
- Town Hall
- Hospital
- School
- Mall
```

## Lists + Input: Building a Dynamic City

Let users add buildings:

```python
city = []

for i in range(3):
    building = input("Enter a building name: ")
    city.append(building)

print()
print("Your city contains:")
for building in city:
    print("-", building)
```

The user enters 3 building names, and they're all stored and displayed.

## Common List Mistakes

**Mistake 1: Index out of range**
```python
colors = ["red", "blue", "green"]  # Indexes: 0, 1, 2
print(colors[3])  # Error! Only 0, 1, 2 exist
```

**Mistake 2: Forgetting lists start at 0**
```python
colors = ["red", "blue", "green"]
print(colors[1])  # Prints "blue", not "red"
```

## Hands-On Exercise

Create a file called `city_list.py`:

```python
print("=== City List Builder ===")
print()

city = []

num = int(input("How many buildings to add? "))

for i in range(num):
    name = input("Building name: ")
    city.append(name)

print()
print("=== Your City ===")
print("Total buildings:", len(city))

for building in city:
    print("-", building)
```

### Try It

3. Enter names like "Library", "Park", "Stadium"
4. See your city list!

## Key Takeaways

1. **Lists hold multiple values** - `["a", "b", "c"]`
2. **Index starts at 0** - first item is `list[0]`
3. **`.append()` adds items** - `list.append("new")`
4. **`len()` counts items** - `len(list)`
5. **Loop through with `for`** - `for item in list:`
